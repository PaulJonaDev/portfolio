## 📂 Proyectos Reales y en funcionamiento.

### 🏥 TurnoSalud

Aplicación web que simula la gestión de turnos de una EPS.

**Funciones principales**

- Mostrar la fila de espera.
- Llamar el siguiente turno.
- Buscar pacientes por nombre o código.
- Cancelar turnos.
- Actualizar automáticamente el contador de personas en espera.

**Tecnologías**

- HTML
- CSS
- JavaScript

## ⚡ Requisitos Previos

Asegúrate de tener instalado tu entorno de desarrollo con las siguientes versiones para garantizar compatibilidad:
*   **Node.js**: `v18.0` o superior
*   **npm**: `v9.0` o superior

## 🛠️ Desarrollo Local

Inicia el entorno de desarrollo local ejecutando los siguientes comandos en tu terminal.

```bash
# 1. Instala todas las dependencias
npm install

# 2. Arranca el servidor de desarrollo en caliente
npm run dev
